# Invent a Word We Need — `canceljoy`

Entry for the make.fun bounty
[u-deranalabs-invent-a-word-we-need-17a020e0](https://make.fun/c/u-deranalabs-invent-a-word-we-need-17a020e0).

## The word

**canceljoy** — the quiet delight when plans fall through and your evening is
suddenly yours.

## How to run

```sh
python3 main.py
```

This writes the entry text to `/output/entry.txt` (creating `/output` if
needed). The program is deterministic: it writes the same bytes on every run,
using only the Python standard library and no network.
